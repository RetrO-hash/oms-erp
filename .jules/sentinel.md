## 2024-05-20 - Hardcoded Secrets in Config Files
**Vulnerability:** Several microservices (`application.yml` and Helm `values.yaml`) contained hardcoded default passwords for databases and Redis instances (e.g., `password: ${SPRING_DATASOURCE_PASSWORD:Ss110110}`, `SPRING_DATASOURCE_PASSWORD: 123456`). Also, external service API keys and secrets were hardcoded in `application.yml` for `baison` and `skyer` (public/private keys).
**Learning:** Developers frequently use default fallback values in configuration files to simplify local development, but these are often committed to version control and deployed, representing a critical risk.
**Prevention:** Remove fallback values for sensitive properties (e.g., use `${SPRING_DATASOURCE_PASSWORD}` or `${SPRING_DATASOURCE_PASSWORD:}`). Use vault or secret management systems for injecting secrets into the environment. Helm charts should not store literal secrets in `values.yaml`; they should be provided via `--set` or secret resources.
