## 2024-05-24 - Hardcoded Secrets in Config Defaults
**Vulnerability:** Found hardcoded database/Redis passwords and RSA public/private keys as fallback default values in `application.yml` files (e.g., `${SPRING_DATASOURCE_PASSWORD:123456}`) and corresponding Java `@ConfigurationProperties` classes (e.g., `private String publicKey = "MFwwDQYJKo..."`).
**Learning:** In Spring Boot applications using `@ConfigurationProperties`, default field values in Java classes can override environment variables if not properly configured. Hardcoding secrets as fallbacks in either YAML files or Java classes exposes sensitive credentials if the expected environment variables are missing, leading to severe security breaches.
**Prevention:** Externalize all secrets using environment variables without hardcoded fallbacks (e.g., `${SPRING_DATASOURCE_PASSWORD:}`). Ensure default field values in Java config classes are `null` rather than hardcoded strings. Fail securely if credentials are not provided in the environment.
