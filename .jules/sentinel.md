## 2024-05-18 - [Hardcoded Cryptographic Keys in Properties]
**Vulnerability:** The codebase had hardcoded public and private RSA keys for cryptography within the `*Properties.java` configuration files across multiple microservices (`GoodsProperties.java`, `AfterSalesProperties.java`, `OrderProperties.java`, `StockProperties.java`, `ChannelProperties.java`, `TagsProperties.java`).
**Learning:** Hardcoding cryptographic keys exposes the keys if the source code is compromised, rendering any encryption relying on these keys useless. In a Spring Boot context, these should rely on externalized configurations (e.g., environment variables) mapped to `@ConfigurationProperties`. When default fields are left non-null, setting external keys can become problematic or easily overlooked.
**Prevention:** Keys should be injected at runtime using environment variables (`${KEY_NAME:}`). The default values in Java classes annotated with `@ConfigurationProperties` should be `null` to ensure the application defaults to external properties safely.
