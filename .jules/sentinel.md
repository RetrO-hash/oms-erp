## 2024-05-18 - MaintainEndpoint Authentication Bypass & Hardcoded Backdoor
**Vulnerability:** The application contained a hardcoded backdoor `secretKey` ("skyer") in `MaintainProperties.java` and `application.yml` which could bypass normal authentication and manage the gateway's maintenance status. In `MaintainEndpoint.java`, the comparison was not constant-time (`configKey.equals(secretKey)`) which could allow a timing attack. In addition, the failed authentication leaked the given `secretKey` in the `RuntimeException` message (`throw new RuntimeException("认证失败，[secretKey=" + secretKey + "]不通过")`) which can be reflected back, creating a risk for log forging and information disclosure.
**Learning:** Default field values in `@ConfigurationProperties` classes can act as hardcoded backdoors, completely undermining security logic meant to fall back to randomly generated keys. Error handling code that reflects user input back in exception messages creates XSS and information disclosure risks.
**Prevention:** Externalize all secrets using environment variables without hardcoded defaults in code. Enforce the use of constant-time string comparison for secrets (e.g. `MessageDigest.isEqual`). Remove reflected user input in error messages.
