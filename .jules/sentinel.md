## 2024-05-06 - Hardcoded Secrets in Configuration Files and Classes
**Vulnerability:** Hardcoded sensitive credentials and keys were found embedded directly within `application.yml` files (e.g., `jwt-key`, `secretKey` for signatures) and within configuration properties classes (e.g., `MaintainProperties.java` having a default value of "skyer").
**Learning:** Even default values intended for local development can become a vulnerability if they accidentally leak into higher environments where these keys are not overridden. It bypasses defense-in-depth and gives attackers an easy avenue for exploitation or unauthorized access if the default keys remain unchanged.
**Prevention:** Never hardcode default secrets in Java configuration classes or YAML properties. Always use environment variables in application files (`${VAR_NAME:}`) without a hardcoded default, and initialize field variables to null in Java code to prevent them from overriding secure properties or providing an insecure default.
