## 2024-05-18 - Hardcoded Secrets in application.yml
**Vulnerability:** Default passwords and RSA keys are hardcoded in application.yml and values.yaml files across multiple microservices (skyer-channel, skyer-tags, skyer-order, skyer-stock, skyer-goods, skyer-after-sales) using Spring Boot default property syntax (e.g., `${SPRING_DATASOURCE_PASSWORD:Ss110110}`).
**Learning:** Default values in configuration files can expose sensitive information if the environment variables are not set. This is a common pattern in Spring Boot applications where default values are provided for convenience during development but can leak into production if not properly overridden.
**Prevention:** Remove hardcoded secrets from configuration files. Rely solely on environment variables or external secret management systems (like HashiCorp Vault, AWS Secrets Manager, etc.) to inject sensitive information at runtime. Use syntax like `${SPRING_DATASOURCE_PASSWORD}` without a default value, or set the default to an empty string/placeholder like `${SPRING_DATASOURCE_PASSWORD:}`.
