## 2024-05-18 - Hardcoded secrets in Spring Boot environment variable fallbacks
**Vulnerability:** Found hardcoded fallback values for sensitive environment variables like `SPRING_DATASOURCE_PASSWORD`, `SPRING_REDIS_PASSWORD`, `SKYER_OAUTH_PASSWORD_PUBLIC_KEY`, and `SKYER_OAUTH_PASSWORD_PRIVATE_KEY` in `application.yml` configuration files. For example: `${SPRING_DATASOURCE_PASSWORD:123456}`.
**Learning:** Spring Boot's property placeholder syntax `${PROPERTY_NAME:default_value}` allows providing a fallback value. Using this for sensitive values like passwords or private keys leads to these secrets being hardcoded and checked into version control. If the environment variable isn't set during runtime, the app will silently fall back to using the insecure default value.
**Prevention:** Always omit the default value for sensitive environment variables in configuration files, e.g., `${SPRING_DATASOURCE_PASSWORD}`. This guarantees that the application will fail fast and securely on startup if the required secret is not provided via the environment, preventing accidental deployments with default, compromised secrets.
