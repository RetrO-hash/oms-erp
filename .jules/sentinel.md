## 2024-05-22 - Insecure Default Spring Boot Configuration Fallbacks
**Vulnerability:** Found multiple `application.yml` configuration files with hardcoded fallback values for sensitive properties (e.g., `${SPRING_DATASOURCE_PASSWORD:123456}`, `${SKYER_OAUTH_PASSWORD_PRIVATE_KEY:MIIB...}`).
**Learning:** Using hardcoded default fallback values in configuration files is a critical security risk. If the intended environment variables fail to load or are not set, the application will silently fall back to these hardcoded values. This can lead to unauthorized access or full compromise of services like databases, redis instances, and OAuth signing keys, especially in local or lower environments that might inadvertently be exposed, or if these secrets are reused.
**Prevention:** Always ensure that default fallback values for secrets and credentials in configuration files (like `${SECRET_KEY:}`) are empty or omit the fallback entirely, forcing the application to fail fast if required secrets are missing, rather than proceeding with insecure default credentials.
